# 니팅 패턴 리더 앱 - Product Requirements Document

## 1. 프로덕트 개요

### 1.1 프로덕트 비전
서술형 니트 도안을 업로드하면 사이즈별로 단/코 수를 자동 분리하고, 진행 상황을 체크할 수 있는 하이브리드 React 앱

### 1.2 핵심 가치 제안
- 복잡한 서술형 도안을 명확하게 정리
- 사이즈별 맞춤 정보 제공으로 혼란 방지
- 진행 상황 체크로 작업 효율성 향상

### 1.3 타겟 유저
- 니팅을 취미로 하는 사람들
- 복잡한 도안을 따라하는데 어려움을 겪는 초중급자
- 여러 프로젝트를 동시에 진행하는 사람들

---

## 2. 기능 요구사항

### 2.1 도안 업로드 (P0)
**유저 스토리**: 사용자로서 서술형 니트 도안 파일을 업로드하여 앱에서 분석하고 싶다

**기능 명세**:
- 파일 업로드 지원 형식: `.pdf`, `.jpeg`, `.jpg`, `.png`
- 드래그 앤 드롭 또는 파일 선택 UI
- 업로드 후 텍스트 추출 및 파싱
- 파싱 실패 시 에러 메시지 표시

**성공 기준**:
- 업로드 후 3초 이내 파싱 완료
- 95% 이상의 텍스트 추출 정확도

---

### 2.2 사이즈별 단/코 수 분리 및 선택 (P0)
**유저 스토리**: 사용자로서 내 사이즈를 선택하면 해당 사이즈에 맞는 단/코 수만 보고 싶다

**기능 명세**:
- 도안에서 사이즈 정보 자동 감지
  - 예: S (M) L (XL) - 85 (90) 95 (100) cm 등
- 사이즈 선택 드롭다운/버튼 UI
- 선택한 사이즈에 해당하는 숫자만 하이라이트/표시
- 사이즈 변경 시 실시간 업데이트

**파싱 로직**:
```
예시 입력: "겉뜨기 20 (24) 28 (32)코를 뜬다"
S 선택 시: "겉뜨기 20코를 뜬다"
M 선택 시: "겉뜨기 24코를 뜬다"
```

**성공 기준**:
- 사이즈 패턴 인식률 90% 이상
- 사이즈 변경 시 0.5초 이내 UI 업데이트

---

### 2.3 진행 단계 분리 및 체크박스 (P0)
**유저 스토리**: 사용자로서 각 작업 단계를 체크하며 진행 상황을 추적하고 싶다

**기능 명세**:
- 도안을 의미 있는 단계로 자동 분리
  - 문단, 번호 매기기, 키워드(예: "다음", "이어서") 기준
- 각 단계 옆에 체크박스 생성
- 체크 상태 로컬 저장 (브라우저 재방문 시 유지)
- 진행률 표시 (예: 15/30 단계 완료 - 50%)

**UI 구성**:
```
☑ 1. 뒤판 만들기
  ☑ 1-1. 85코를 만든다
  ☑ 1-2. 1단부터 40단까지 메리야스 뜨기를 한다
□  2. 소매 만들기
  □ 2-1. 40코를 만든다
```

**성공 기준**:
- 단계 분리 정확도 85% 이상
- 체크 상태 로컬 스토리지 저장/복원 100%

---

### 2.4 진행 상황 관리 (P1)
**기능 명세**:
- 전체 진행률 시각화 (프로그레스 바)
- 완료한 단계 / 전체 단계 카운트
- 진행 상황 초기화 기능

## 3. 기술 스택

### 3.1 코어 기술
- **프레임워크**: Next.js 15 (App Router)
- **패키지 매니저**: pnpm
- **린터/포매터**: Biome
- **언어**: TypeScript
- **스타일링**: Tailwind CSS
- **상태 관리**: Zustand 또는 React Context
- **로컬 스토리지**: localStorage API

### 3.2 파일 처리
- **PDF**: pdf-parse 또는 pdf.js
- **DOCX**: mammoth.js
- **텍스트**: 네이티브 File API

### 3.3 배포
- Vercel (권장) 또는 Netlify

---

## 4. 디자인 시스템

### 4.1 디자인 원칙
- **미니멀리즘**: 불필요한 요소 제거, 콘텐츠에 집중
- **가독성 우선**: 명확한 타이포그래피, 충분한 여백
- **단일 강조색**: 브랜드 컬러 하나로 일관성 유지

### 4.2 컬러 팔레트
```
Primary (강조색): #6366F1 (Indigo-500)
Background: #FFFFFF
Text Primary: #1F2937 (Gray-800)
Text Secondary: #6B7280 (Gray-500)
Border: #E5E7EB (Gray-200)
Success (체크): #6366F1
```

### 4.3 타이포그래피
- **제목**: Inter 또는 Pretendard, 24px, Bold
- **본문**: Inter 또는 Pretendard, 16px, Regular
- **단계 텍스트**: 18px, Medium

### 4.4 컴포넌트 스타일
- **버튼**: 라운드 8px, 강조색 배경, 흰색 텍스트
- **체크박스**: 커스텀 디자인, 체크 시 강조색
- **파일 업로드**: 점선 보더, 드래그 시 강조색 배경
- **프로그레스 바**: 심플한 라인 스타일, 강조색

## 6. 유저 플로우

```
1. 앱 접속
   ↓
2. 도안 파일 업로드 (드래그 또는 선택)
   ↓
3. 파싱 완료 및 사이즈 선택 화면 표시
   ↓
4. 사이즈 선택 (예: M)
   ↓
5. 선택한 사이즈에 맞는 도안 표시 + 체크박스
   ↓
6. 작업하며 각 단계 체크
   ↓
7. 진행률 자동 업데이트
   ↓
8. (선택) 다른 사이즈로 변경 또는 진행 상황 초기화
```

## 7. 비기능 요구사항

### 7.1 성능
- 초기 로딩: 2초 이내
- 파일 파싱: 3초 이내
- 체크박스 토글: 즉각 반응 (100ms 이내)

### 7.2 접근성
- 키보드 네비게이션 지원
- 스크린 리더 호환
- WCAG 2.1 AA 레벨 준수

### 7.3 반응형
- 모바일 (320px~768px)
- 태블릿 (768px~1024px)
- 데스크톱 (1024px+)

### 7.4 브라우저 지원
- Chrome (최신 2개 버전)
- Safari (최신 2개 버전)
- Firefox (최신 2개 버전)
- Edge (최신 2개 버전)

- Next.js 프로젝트 세팅 (pnpm, Biome)
- 기본 UI 레이아웃
- 파일 업로드 UI

- 디자인 개선
- 에러 핸들링
- 성능 최적화
- 베타 테스트

**총 예상 기간**: 4주
