# 기술 스택

## 프론트엔드
- **프레임워크**: Next.js 15 (App Router)
- **언어**: TypeScript (strict mode)
- **스타일링**: Tailwind CSS + shadcn/ui
- **테마**: next-themes
- **패키지 매니저**: pnpm
- **린터/포매터**: Biome

## 파일 처리
- **PDF**: pdf-parse
- **DOCX**: mammoth
- **텍스트**: File API (native)

## 저장소
- **로컬 스토리지**: localStorage API
  - 패턴 데이터
  - 체크박스 상태
  - 선택한 사이즈

## 주요 라이브러리
- **UI**: shadcn/ui (Button, Card, Checkbox, Progress 등)
- **아이콘**: lucide-react
- **유틸리티**: clsx, tailwind-merge
