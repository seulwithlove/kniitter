# 유저 플로우

## 메인 플로우
1. 앱 접속
   - 로고와 ThemeToggle 표시
   - 파일 업로드 영역 표시

2. 도안 업로드
   - 드래그 앤 드롭 또는 파일 선택
   - 지원 형식: txt, pdf, docx, md
   - 로딩 인디케이터 표시

3. 파싱 완료
   - 성공 Toast 알림
   - 사이즈 선택 UI 표시
   - 자동으로 첫 번째 사이즈 선택

4. 사이즈 선택
   - 버튼 형태로 사이즈 목록 표시
   - 클릭 시 해당 사이즈 내용으로 업데이트
   - 애니메이션 효과

5. 도안 작업
   - 단계별로 체크박스와 내용 표시
   - 체크 시:
     - 체크박스 체크
     - 텍스트 스트라이크스루
     - 로컬 스토리지 저장
     - 진행률 업데이트

6. 진행 중 액션
   - 다른 사이즈로 변경 가능
   - 진행 상황 초기화 가능
   - 새 도안 업로드 가능

## 에러 플로우
- 파일 형식 오류 → Alert 표시
- 파싱 실패 → Alert 표시 + 재시도 버튼
- 네트워크 오류 → Toast 알림
