# 핵심 기능 명세

## 1. 도안 업로드 (P0)
- 지원 형식: txt, pdf, docx, md
- 드래그 앤 드롭 UI
- 파싱 후 텍스트 추출

## 2. 사이즈별 단/코 수 분리 (P0)
### 파싱 예시
입력: "겉뜨기 20 (24) 28 (32)코를 뜬다"
- S 선택 시: "겉뜨기 20코를 뜬다"
- M 선택 시: "겉뜨기 24코를 뜬다"
- L 선택 시: "겉뜨기 28코를 뜬다"
- XL 선택 시: "겉뜨기 32코를 뜬다"

### 정규식 패턴
- `\d+\([\d,\s]+\)` - 숫자(숫자, 숫자) 패턴 감지

## 3. 진행 단계 분리 및 체크박스 (P0)

- 진행률 표시 (완료/전체)

## 4. 진행 상황 관리 (P1)
